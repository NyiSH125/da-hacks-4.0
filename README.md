# da-hacks-4.0
Social Matching App

## Features

- **Profile Management**: Create and save your profile with tags and preferences
- **Category Selection**: Choose from Education, Sports, Gaming, and Roommates
- **AI-Powered Matching**: Intelligent matching using OpenAI GPT models
- **Natural Language Input**: Describe preferences in plain English
- **Tag-Based Matching**: Traditional tag overlap matching (works without AI)

## AI Features

This app includes AI-powered matching capabilities using **Google Gemini's FREE API**. See [AI_SETUP.md](./AI_SETUP.md) for setup instructions.

### Quick Start with AI (FREE!)

1. Get a free Google Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Enter it when prompted in the app
3. Use the "Natural language preferences" field on the profile page
4. Get AI-enhanced match scores and explanations

**No credit card required!** Gemini's free tier is perfect for this app.

## Tech Stack

- Vanilla JavaScript
- OpenAI API (GPT-4o-mini)
- LocalStorage for data persistence
- Modern CSS with dark theme
